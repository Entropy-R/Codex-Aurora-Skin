# Windows Changelog

## Next

- v1.0.1 候选统一版本字段，等待 Windows PowerShell、Setup.exe 与实机布局门禁。
- 新建普通任务和项目内任务的输入框沿用 Codex 原生纵向布局，不再被共享主页
  固定高度规则推离视口。
- 管理器连接中断时显示可操作的简体中文提示，同时保留 HTTP 与业务错误原文。
- 改为简体中文浏览器主题管理器，移除托盘、登录启动和更新检查。
- 引入共享离线资源库、用户图片导入与浅暗独立明暗调节。
- 主题固定跟随 Codex 官方外观，不再写入 `config.toml`。
- Setup.exe 只发布许可明确的内置资源，并保留用户主题与覆盖值。
- Release 地址统一为 `Entropy-R/Codex-Aurora-Skin`。
- 修复管理页刷新后令牌丢失，以及调节亮度、背景压暗时的预览报错。
- 统一项目页、对话页和管理器预览的背景合成，并让管理令牌在启动时无感建立。
- 新增浅暗独立的界面底色强度，降低原生面板白底并移除任务页装饰文案。
- 开始菜单改用无控制台启动器，消除打开主题管理器时的 PowerShell 窗口闪烁。
- 由原生启动器验证管理服务并打开默认浏览器，修复后台已启动但点击入口无响应。
