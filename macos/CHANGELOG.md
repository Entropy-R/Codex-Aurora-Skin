# macOS Changelog

## Next

- 菜单栏常驻 App 改为一次性启动器，安装引擎、打开管理器后退出。
- 移除 SwiftBar、登录启动、更新检查和推广入口。
- 引入与 Windows 共用的离线主题库、管理 API 和浅暗明暗调节。
- 主题固定跟随 Codex 官方外观，不再写入 `config.toml`。
- DMG 只包含许可明确的内置资源，并保留用户主题与覆盖值。
- 修复管理页刷新后令牌丢失，以及调节亮度、背景压暗时的预览报错。
- 统一项目页、对话页和管理器预览的背景合成，并让管理令牌在启动时无感建立。
- 新增浅暗独立的界面底色强度，降低原生面板白底并移除任务页装饰文案。
